# قائمة اختبارات مشروع صياغة (Siyagah Checklist)

## 1. اختبارات واجهة المستخدم (Frontend)
- [ ] التأكد من ظهور اتجاه الصفحة من اليمين إلى اليسار (RTL) بشكل صحيح.
- [ ] تجربة إضافة نص بطول 100 حرف والضغط على "أعد الصياغة ✨".
- [ ] التأكد من تعطيل الأزرار أثناء معالجة الطلب (Loading State).
- [ ] اختبار زر "مسح" والتأكد من تفريغ المدخلات والمخرجات.
- [ ] اختبار زر "نقل إلى المدخلات" والتأكد من نسخ النتيجة إلى خانة النص الأصلي.
- [ ] اختبار زر "نسخ 📋" والتحقق من حفظ النص في المحفظة.
- [ ] اختبار زر "تحميل TXT 💾" والتحقق من تنزيل ملف نصي برموز UTF-8 صحيحة.
- [ ] اختبار اختصار الأزرار `Ctrl + Enter` لإرسال الطلب.

## 2. اختبارات خادم Cloudflare Worker & API
- [ ] إرسال طلب POST بمحتوى فارغ والتأكد من استلام كود 400 بركادة خطأ واضحة.
- [ ] إرسال نص يزيد عن 12,000 حرف والتحقق من الرفض.
- [ ] التأكد من عدم وجود مفتاح API في كود الفتح أو الاستجابات المرجعة.
- [ ] اختبار حظر طلبات CORS من نطاقات غير مصرح بها عند ضبط `ALLOWED_ORIGIN`.
